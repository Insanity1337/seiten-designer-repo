# Sicherheitslücken melden

Bitte melde Sicherheitslücken **nicht** über öffentliche Issues.

- Bevorzugt: auf GitHub im Tab **Security → Report a vulnerability** (private Meldung).
- Alternativ per E-Mail an **jdthereal@tuta.com**.

Hilfreich sind: betroffene Version, Schritte zum Nachstellen und – falls vorhanden – eine Beispielseite
oder ein Beispiel-Export der Anpassungen. Ich melde mich in der Regel innerhalb weniger Tage.

## Was die Erweiterung tut (und was nicht)

- Alle Anpassungen werden ausschließlich lokal in `browser.storage.local` gespeichert.
- Es werden keine Daten an den Entwickler oder Dritte übertragen; es gibt keine Netzwerkzugriffe.
- Es wird kein Code nachgeladen.
